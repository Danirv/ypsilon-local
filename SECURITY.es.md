# Política de seguridad

## Versiones soportadas

Las correcciones de seguridad se aplican a la última versión publicada.

## Informar de una vulnerabilidad

No publiques credenciales, material de emparejamiento, claves privadas, tokens de cuenta, identificadores únicos de dispositivo ni detalles de explotación que puedan poner a usuarios en riesgo inmediato.

Si GitHub Private Vulnerability Reporting está habilitado para este repositorio, úsalo. En caso contrario, abre un issue mínimo solicitando un canal de contacto privado y omite los detalles sensibles.

Para errores funcionales normales, utiliza la plantilla de bug report.

## Límite de seguridad

Esta integración puede cambiar configuración, cerrar/controlar comportamiento relacionado con el agua e iniciar un ciclo mecánico de regeneración. No es un controlador de seguridad certificado y no debe ser la única protección frente a inundaciones, condiciones inseguras de fontanería o daños en el equipo.
